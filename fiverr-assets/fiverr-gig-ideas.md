# Fiverr Gig Ideas — Three Directions

Three gigs, each anchored to a project the portfolio can prove. Titles fit
Fiverr's 80-char limit and start with "I will", per platform convention.
**No prices set** — decide those against the market when publishing; the
package structure below is about scope, not cost.

---

## Gig 1 — Cross-platform app development (anchor: NaqiVerse + Grocs)

**Title:** I will build your mobile app with React Native and Expo, end to end

**Category:** Programming & Tech → Mobile Apps → Cross-platform Development

**Gallery:** `naqiverse-1-games.png`, `grocs-1-capture.png`, `naqiverse-3-polish.png`

**Overview copy (~700 chars):**
> Your app idea, built properly: architecture, screens, state, storage and
> ship-ready polish — by one engineer who has done it end to end. My portfolio
> includes a five-game arcade app (physics engine, progression, leaderboards,
> coin economy) and a local-first AI recipe companion (OCR capture pipeline,
> SQLite full-text search, on-device ML). I write game-grade TypeScript:
> logic separated from UI, honest loading/error/empty states, offline-first
> where it matters, haptics and motion where they earn their place. You get
> clean code, a README your next developer will thank you for, and builds
> ready for the stores.

**Package skeleton:**
- *Basic* — single-screen utility or prototype; core flow working on Android + iOS.
- *Standard* — multi-screen app with local storage, navigation and one integration (API, auth or payments).
- *Premium* — full product: complex state, offline support, animations, store-ready builds and handover docs.

**Buyer requirements:** what the app does in one paragraph; rough screen list or reference apps; any designs (Figma) or "design it for me"; target platforms.

**FAQ seeds:** Do you do iOS and Android? (Yes — one codebase.) · Can you work from a rough idea? (Yes — the first deliverable is a written scope.) · Where can I see real work? (Portfolio link.)

## Gig 2 — AI features in mobile apps (anchor: Grocs + AIMARA AI lane)

**Title:** I will add AI features to your app — OCR, chat, translation, on-device ML

**Category:** Programming & Tech → AI Development

**Gallery:** `grocs-2-private.png`, `aimara-1-secure-chat.png`, `grocs-3-pantry.png`

**Overview copy (~680 chars):**
> AI in production apps needs more than an API call: it needs pipelines,
> review states and graceful failure. I've shipped both kinds — fully
> on-device AI (a recipe app whose OCR + language model never sends data off
> the phone) and server-side AI with governance (enterprise messaging where
> translation, paraphrasing and message-polish suggestions pass a human
> review window before anything sends). I can add capture pipelines (image /
> screenshot / video → structured data), multilingual features, smart
> matching and recommendation logic — designed so users stay in control and
> your data stays where it should.

**Package skeleton:**
- *Basic* — one AI feature integrated into an existing app (e.g. OCR import, translation).
- *Standard* — an AI pipeline with states: queued → processing → review → saved, with retries and error design.
- *Premium* — on-device or privacy-first AI architecture, or multi-feature AI lane with human-review UX.

**Buyer requirements:** the feature in plain words; where data may and may not go (cloud OK / on-device only); existing stack.

**FAQ seeds:** Can it run fully offline? (Often yes — my portfolio has a fully on-device example.) · Which models/APIs? (Chosen per constraint — privacy, cost, quality.)

## Gig 3 — Real-time & admin systems (anchor: AIMARA)

**Title:** I will build secure real-time features — chat, dashboards, admin workflows

**Category:** Programming & Tech → Web & Mobile Development

**Gallery:** `aimara-2-operations.png`, `aimara-3-governance.png`, `aimara-1-secure-chat.png`

**Overview copy (~660 chars):**
> Real-time is where apps usually break: sockets, presence, permissions,
> audit trails. I built the mobile client of an enterprise operations
> platform — governed channels, live dashboards, case management,
> freeze/archive approval workflows, biometric app lock and encrypted
> storage — on Ionic Angular, FastAPI and Supabase with row-level security.
> I can bring that discipline to your product: chat and notifications that
> survive bad networks, role-based admin surfaces, approval flows, and
> security features users can feel. Enterprise texture, startup speed.

**Package skeleton:**
- *Basic* — one real-time feature (live feed, notifications, presence) in an existing app.
- *Standard* — chat or dashboard module with roles and permissions.
- *Premium* — full operations surface: real-time data, workflows, audit logging, device-security hardening.

**Buyer requirements:** current stack; who the roles/users are; compliance or security constraints.

**FAQ seeds:** Can you sign an NDA? (Yes — my flagship project is under one.) · Backend too? (Yes — FastAPI/Supabase, or I integrate with yours.)
